# M7  
**Радиосвязь: передатчик-приемник** — моделирование канала передачи с амплитудной модуляцией, высокочастотными помехами, резонансным RLC-контуром приемника, выпрямляющим детектором и RC-фильтром низких частот.

Рассматривается цепочка:
1. Формирование исходного информационного сигнала (аудиоподобный НЧ-сигнал)
2. Модуляция на несущей частоте (AM)
3. Добавление ВЧ-помех в канале распространения
4. Выделение сигнала резонансным RLC-контуром
5. Детектирование огибающей (идеальный выпрямитель)
6. Сглаживание RC-фильтром и восстановление информации

---

## Физическая модель

Передатчик формирует AM-сигнал:

$$
s_{tx}(t) = (1 + m \cdot x(t))\cos(2\pi f_c t),
$$

где:
- $x(t)$ — исходный информационный сигнал,
- $m$ — индекс модуляции,
- $f_c$ — несущая частота.

На канале к сигналу добавляются случайные ВЧ-помехи:

$$
s_{rx}(t) = s_{tx}(t) + n_{hf}(t).
$$

Приемник моделируется как полосовой RLC-контур, настроенный на $f_c$, после чего применяется выпрямление и RC-фильтр нижних частот для восстановления огибающей.

## Входные параметры

| Параметр | Ограничения | Назначение |
| --- | --- | --- |
| Время моделирования `duration_s` (с) | $0.001 \le t \le 1.0$ | Длительность расчета |
| Частота дискретизации `sample_rate_hz` (Гц) | $2\cdot 10^5 \le f_s \le 5\cdot 10^7$ | Точность дискретной модели |
| Несущая частота `carrier_freq_hz` (Гц) | $2\cdot 10^4 \le f_c \le 5\cdot 10^6$ | Частота AM-несущей |
| Индекс модуляции `modulation_index` | $0.05 \le m \le 1.0$ | Глубина AM-модуляции |
| Зерно генератора `seed` | $0 \le seed \le 10^6$ | Повторяемость шума |
| Относительная амплитуда помех `noise_relative_amplitude` | $0 \le A_n \le 2.0$ | Интенсивность ВЧ-помех |
| Число синус-компонент помех `noise_components` | $1 \le N \le 400$ | Спектральная сложность помех |
| Нижняя граница частот помех `noise_min_freq_hz` (Гц) | $10^3 \le f_{min} \le 2\cdot10^7$ | Низ диапазона помех |
| Верхняя граница частот помех `noise_max_freq_hz` (Гц) | $2\cdot10^3 \le f_{max} \le 3\cdot10^7$ | Верх диапазона помех |
| Сопротивление `rlc_resistance_ohm` (Ом) | $0.01 \le R \le 10^4$ | Добротность RLC-контура |
| Индуктивность `rlc_inductance_h` (Гн) | $10^{-7} \le L \le 10$ | Параметр резонансного контура |
| Коэффициент детектора `envelope_scale` | $0.01 \le k \le 100$ | Масштаб огибающей |
| Постоянная времени RC `lowpass_tau_s` (с) | $10^{-7} \le \tau \le 1$ | Сглаживание и подавление ВЧ-компонент |

## Выходные данные

Программа строит графики основных этапов:
- исходный информационный сигнал,
- AM-сигнал передатчика,
- сигнал после канала с помехами,
- выход RLC-контура и выпрямленная огибающая,
- сравнение исходного и восстановленного сигналов.

Также выводятся метрики качества восстановления:
- среднеквадратичная ошибка (MSE),
- коэффициент корреляции между исходным и восстановленным сигналами.

## Установка и запуск с помощью uv

1) Установите `uv` (если ещё не установлен), один из вариантов:
- `curl -fsSL https://astral.sh/uv/install.sh | sh`
- `pip install uv`

2) Создайте виртуальное окружение:
`uv venv .venv && source .venv/bin/activate`

3) Установите зависимости:
`uv sync`

## Запуск модели

Включите окружение и запустите:
`uv run python -m src.m7_radio.main`
