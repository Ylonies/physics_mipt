# M3: Магнитная пробка

Данная программа моделирует движение заряженной частицы в аксиально-симметричном магнитном поле двух одинаковых токовых колец в параллельных плоскостях. Поле считается по закону Био–Савара, траектория — численным интегрированием уравнений движения в поле Лоренца.

## Физическая модель

Магнитное поле двух колец радиуса $R$ с током $I$ в плоскостях $z = \pm d/2$ суммируется из вкладов сегментов проводника (численный Biot–Савар). Для ускорения на траектории используется предварительный расчёт $B_r$, $B_z$ на сетке $(r,z)$ с билинейной интерполяцией.

Движение частицы с зарядом $q$ и массой $m$:

$$m\frac{d\vec{v}}{dt} = q\,(\vec{v}\times\vec{B}), \qquad \frac{d\vec{r}}{dt} = \vec{v}.$$

Интегрирование — метод Рунге–Кутты 4-го порядка. На оси симметрии модуль сравнивается с аналитической формулой для $B_z(0,z)$.

## Входные параметры

Параметры задаются в файле `config.py` (легко изменить без правок кода).

1. **Радиус колец $R$ (м)** — $R > 0$.
2. **Расстояние между плоскостями колец $d$ (м)** — $d > 0$.
3. **Ток в кольцах $I$ (А)** — $I > 0$, подбирается так, чтобы ларморовский радиус был мал по сравнению с $R$.
4. **Заряд и масса частицы $q$, $m$** — в СИ; по умолчанию протон.
5. **Число сегментов на кольцо**, **размер сетки поля** $N_r \times N_z$, **шаг по времени** (доля циклотронного периода), **время моделирования** $t_{\max}$, **начальные $\vec{r}_0$, $\vec{v}_0$**.

## Запуск модели

Интерактивно (окна с графиками):

```bash
uv run python -m src.m3_magnetic_mirror.main
```

Сохранение рисунков в каталог без GUI:

```bash
MPLBACKEND=Agg uv run python -m src.m3_magnetic_mirror.main --save-plots output/m3_plots
```

В консоль выводятся опорное поле $B_{\mathrm{ref}}$, шаг $dt$, число шагов и момент вылета по $|z|$ (если частица покинула заданную область).

## Результаты расчёта

* **$B_z(z)$ на оси** — сопоставление аналитической кривой и численного Biot–Савара.
* **Траектория** — 3D, проекция $r$–$z$, $r(t)$, $z(t)$, относительное отклонение кинетической энергии от начального значения.
* **$|B|(r,z)$** — контурная карта модуля поля (видны «пробки» у колец и минимум между ними).
