# M1: Основная задача электростатики

Данная программа моделирует электростатическое поле между двумя параллельными металлическими дисками радиуса R . Здесь учитываются краевые эффекты с помощью численного метода моментов.

## Физическая модель
Поверхность каждого проводника разбивается на малые элементы. Система уравнений для поиска неизвестных зарядов $q_i$ на каждом элементе решается из условия постоянства потенциала на проводнике:
$$\phi_i = \sum_{j=1}^{2N} A_{ij} q_j = V_i$$
где $A_{ij}$ — коэффициенты потенциала, зависящие от геометрии системы.

## Входные параметры
1. **Радиус электродов $R$ (м)**
   - Ограничения: $R > 0$

2. **Расстояние между пластинами $d$ (м)**
   - Ограничения: $d > 0$

3. **Разность потенциалов $\Delta\phi = V$ (В)**
   - Ограничения: Любое вещественное число (обычно $V \neq 0$).

4. **Количество разбиений (rings/sectors)**
   - Ограничения: $N > 10$ для приемлемой точности.

## Запуск модели

Запустите основной скрипт для расчета распределения зарядов, емкости и визуализации поля:

```bash
uv run python -m src.m1_electrostatics.main

```

Программа выведет рассчитанную емкость $C$ и сравнит её с теоретической емкостью идеального плоского конденсатора. 
Также будет построена картина силовых линий.

## Результаты расчета

* **Распределение $\sigma(r)$**: График плотности заряда, демонстрирующий рост заряда к краям диска.
* **Емкость $C$**: Численное значение с учетом краевых эффектов.
* **Поле $\vec{E}$**: Визуализация векторов напряженности в пространстве между электродами.
