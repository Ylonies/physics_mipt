# M5
**Автогенератор на туннельном диоде** — численное моделирование нелинейного RLC-контура с источником питания и туннельным диодом.

---

## Физическая постановка

Аппроксимация ВАХ диода из условия:
`I_D(U_D) = a U_D^3 + b U_D^2 + c U_D`, при `U_D > 0`  
`I_D(U_D) = 0`, при `U_D <= 0`

где
`a = 4e-3 A/V^3`, `b = -16e-3 A/V^2`, `c = 17e-3 A/V`.

Уравнения модели:
`L * dI/dt = ε - R*I - U`  
`C * dU/dt = I - I_D(U)`

---

## Ответы на вопросы задания (выводятся в консоль)

1. **Автогенерация** — линейный критерий `g_D(U₀)<0`, `U₀∈(0.73;1.93) В`, `RC+L·g_D<0`; проверка моделированием.
2. **Почти синусоида** — малый THD при `RC+L·g_D≈0`; перебор типичных `R,L,C`.
3. **Максимальная амплитуда** — полуразмах `U_D` в установившемся режиме + оценка по ВАХ.

Критерий из теории: при `R=8 Ом`, `L=1 мГн` автогенерации обычно **нет** (недостаточная отриц. проводимость). Для колебаний нужны меньшие `R` и/или большие `L` (по умолчанию `R=2 Ом`, `L=5 мГн`).

### Проверка на краях диапазона

См. раздел **Тесты** — команда `edge_physics_test.py -s` выводит сводную таблицу.

| Край | Ожидание | Результат проверки |
|------|----------|-------------------|
| R=0.5 Ом | автогенерация | да |
| R=50 Ом | затухание | нет колебаний |
| L=0.1 мГн | сильное затухание (RC≫\|Lg\|) | нет |
| C=100 мкФ | затухание | нет |
| ε=0.5 В | U₀ вне отриц. ветви → нет | нет |
| ε=2.8 В | U₀≈2.97 В, вне (0.73;1.93) → нет | нет |
| t=5 мс | колебания есть (≥ несколько периодов) | да |

## Входные параметры

Параметры вводятся интерактивно в консоли:
- `ε` (В),
- $R$ (Ом),
- $L$ (Гн),
- $C$ (Ф),
- начальные условия $U(0)$ и $I(0)$,
- время моделирования,
- число временных точек.

### Ограничения на входные параметры

Технические границы ввода (в программе выводятся при запуске):

- ε: `0.3 … 3.5` В  
- R: `0.1 … 100` Ом  
- L: `1e-5 … 0.2` Гн  
- C: `1e-8 … 1e-3` Ф  
- U(0): `0 … 3.5` В, I(0): `±1` А  
- время: `0.001 … 1` с, точек: `1000 … 500000`  

**Автогенерация** на краях этих диапазонов часто **не возникает** (это не ошибка расчёта): нужна рабочая точка в «отрицательной» ветви ВАХ (0.73…1.93 В) и `RC+L·g_D<0`. Практичные стартовые значения: ε≈1.2 В, R≈2 Ом, L=5 мГн, C=2 мкФ.  

Коэффициенты ВАХ туннельного диода фиксированы по условию задачи:
- `a = 4e-3 A/V^3`
- `b = -16e-3 A/V^2`
- `c = 17e-3 A/V`

---

## Выходные данные

В консоль выводятся:
- факт автогенерации,
- максимальная амплитуда,
- основная частота,
- THD и коэффициент синусоидальности.

На графиках:
- `U_D(t)`,
- `I_L(t)` и `I_D(t)`,
- фазовый портрет `I_L(U_D)`,
- спектр установившихся колебаний.
