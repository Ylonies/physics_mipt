# M5
**Автогенератор на туннельном диоде** — численное моделирование нелинейного RLC-контура с источником питания и туннельным диодом.

---

## Физическая постановка

Аппроксимация ВАХ диода из условия:
`I_D(U_D) = a U_D^3 + b U_D^2 + c U_D`, при `U_D > 0`  
`I_D(U_D) = 0`, при `U_D <= 0`

где
`a = 4e-3 A/V^3`, `b = -16e-3 A/V^2`, `c = 17e-3 A/V`.

Уравнения модели:
`L * dI/dt = ε - R*I - U`  
`C * dU/dt = I - I_D(U)`

---

## Что исследуется

Для выбранных `R`, `L`, `C` и начальных условий программа оценивает:
- возникает ли автогенерация,
- насколько колебания близки к синусоидальным (по THD),
- максимальную амплитуду напряжения на диоде,
- оценку основной частоты колебаний.

---

## Входные параметры

Параметры вводятся интерактивно в консоли:
- `ε` (В),
- $R$ (Ом),
- $L$ (Гн),
- $C$ (Ф),
- начальные условия $U(0)$ и $I(0)$,
- время моделирования,
- число временных точек.

### Ограничения на входные параметры

- ЭДС источника: `0 <= ε <= 10` В  
- Сопротивление: `0.01 <= R <= 10000` Ом  
- Индуктивность: `1e-7 <= L <= 10` Гн  
- Емкость: `1e-10 <= C <= 1` Ф  
- Начальное напряжение: `-5 <= U(0) <= 5` В  
- Начальный ток: `-5 <= I(0) <= 5` А  
- Время моделирования: `1e-4 <= t_end <= 10` с  
- Число точек сетки: `500 <= N <= 200000`  

Коэффициенты ВАХ туннельного диода фиксированы по условию задачи:
- `a = 4e-3 A/V^3`
- `b = -16e-3 A/V^2`
- `c = 17e-3 A/V`

---

## Выходные данные

В консоль выводятся:
- факт автогенерации,
- максимальная амплитуда,
- основная частота,
- THD и коэффициент синусоидальности.

На графиках:
- `U_D(t)`,
- `I_L(t)` и `I_D(t)`,
- фазовый портрет `I_L(U_D)`,
- спектр установившихся колебаний.
