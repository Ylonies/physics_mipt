# M9
Подзорная труба: трассировка лучей, изображение плоского объекта.

## Ввод

**Режим:** `1` — тонкие линзы, `2` — толстые сферические.

**Параметры системы** (Enter — по умолчанию):

- расстояние от объекта до объектива, м — `0.05 … 2.0` (по умолчанию `0.25`)
- фокусное расстояние объектива, м — `0.02 … 1.0` (по умолчанию `0.2`)
- фокусное расстояние окуляра, м — `0.01 … 0.3` (по умолчанию `0.05`)
- положение окуляра по оси, м — `(s + 0.05) … 3.0`, где `s` — расстояние до объектива (по умолчанию `1.31`; окуляр должен быть правее промежуточного изображения объектива)
- полувысота объекта, м — `0.001 … 0.05` (по умолчанию `0.01`)

Для режима `2` дополнительно: толщина линзы, мм — `1 … 40` (по умолчанию `12`).
